RPA — Carga masiva de enfermedades

Sube un archivo JSON con el formato de EjemploRPA.json y el robot completará el alta por ti, clasificando automáticamente cada enfermedad por tipo.

1. Archivo de origen

Campos esperados: nombre_enfermedad, descripcion, sintomas_asociados, medicamentos_contraindicados, sistema_cuerpo. El "tipo" (crónico, viral, bacteriano, inmunológico) se infiere automáticamente a partir de la descripción. Campo opcional: tratamiento_recomendado (lista de medicamentos que tratan la enfermedad — ver Ejemplo Archivo RPA V2.json); si se incluye, también se registra automáticamente esa relación.

Este botón ejecuta el modo rápido del RPA (llama directamente a la capa de persistencia). Para la automatización visual con PyAutoGUI —la que se graba en el video de evidencia— corre python scripts/ejecutar_rpa_gui.py desde otra terminal; ver el Manual Técnico, sección "Configuración del robot RPA".
